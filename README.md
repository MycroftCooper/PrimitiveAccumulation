# Primitive Accumulation

Primitive Accumulation 是一款跨 iOS、Android、Windows 和 macOS 的本地优先个人财富成长工具，也可以理解为一个“赛博存钱罐”。它不是逐笔记账软件，不是券商或交易平台，MVP 不接入银行、券商或理财平台 API。

## 核心价值

- 直观看见净资产及其长期成长；
- 理解资产配置、负债结构和财务安全感；
- 轻量维护固定收入、刚性支出和可选的基础生活费估计，而非记录每笔消费；
- 通过投资决策日志记录买卖理由、复盘决策并建立纪律，不提供买卖建议；
- 将主题、动效和正反馈作为核心体验，同时坚持真实、可读和非羞耻化表达。

## MVP 范围与边界

- 面向个人单人使用，MVP 使用个人资产空间；
- 数据由用户手动维护，并只保存在设备本地 SQLite；
- 无服务器、无账号，支持从设置手动导出和恢复加密备份；
- 正式覆盖 iOS、Android、Windows 和 macOS，移动端优先打磨，桌面端保持同等核心功能；
- 不做逐笔记账、自动行情追踪或金融机构 API 接入；
- 本地数据可能因卸载应用、更换设备或设备损坏而丢失；
- 用户主动选择的云存档、AI 资产负债与投资复盘、OCR 图片识别辅助录入计划在第二版提供；
- 第二版仍保留纯本地模式，AI 只做分析与反思，不直接给出买卖建议。

## 技术路线

- 客户端框架：Flutter；
- 开发语言：Dart；
- MVP 数据库：设备本地 SQLite；
- 第二版服务器数据库：PostgreSQL，仅用于用户主动开启的云端能力；
- MVP 由 Flutter 客户端直接访问本地 SQLite，不运行后端；
- 第二版 Flutter 客户端只能通过明确的 API 契约访问后端，绝不直接连接 PostgreSQL；
- 后端 Web 框架、部署平台、云服务和其他第三方依赖尚未选定。

## 开发原则

### 本地优先与数据主权

MVP 数据只存在用户设备本地，不上传服务器。涉及云端的能力必须由用户在后续版本中主动选择。

### 真实快照，不伪造数据

底层只保存用户真实提交时间的不可变快照。趋势查看可以动态聚合，但不能补造没有录入的时间点，也不能自动虚构账面变化原因。

### 情绪价值不误导

主题、动效和庆祝反馈服务于财富感知与数据理解。净资产变化不冒充投资收益，资产下降、市场波动和还债均使用稳定、非羞耻化表达。

### 前后端分离

MVP 客户端只访问本地 SQLite。第二版客户端经 API 访问后端，永不直接连接 PostgreSQL。

### 主题集中管理

主题配置、主题切换、视觉资源和动效语义集中管理，业务页面只消费统一主题语义，避免将具体皮肤逻辑散落在各功能模块。

### 依赖成熟可靠

除已经确认的 Flutter、Dart、SQLite 和第二版 PostgreSQL 外，其他依赖待后续选择。只采用主流、长期维护、文档完整且四端支持成熟的方案。
