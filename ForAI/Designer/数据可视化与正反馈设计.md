# 数据可视化与正反馈设计

> 本文档用于产品设计审阅，定义 MVP 的数据可视化、信息层级与正反馈边界。所有展示均以真实录入数据和既定指标口径为基础。

## 1. 设计总原则

- **首页感受成长，分析页理解原因**：首页优先传递清晰、积极的财富成长感受；分析页承载结构、变化和安全感的理解。
- **高情绪价值，但不做金融终端**：视觉和动效应有表现力，同时保持个人财富成长工具的定位，不堆叠实时行情或专业交易终端信息。
- **真实数据优先**：所有图表、变化和反馈必须来自真实快照或用户录入数据。
- **非羞耻化反馈**：资产下降、市场波动或还债场景使用稳定、中性的表述，不评价用户，也不制造焦虑。
- **可读性优先**：金额、比例、趋势和真实日期必须易于理解；主题、皮肤和动效不能压过数据。

## 2. MVP 六个核心可视化

### 2.1 净资产成长曲线

- 使用真实、不可变的净资产快照；
- 支持日、周、月、季度、年和自定义区间的动态查看；
- 每个有记录的周期取该周期最后一次真实快照；
- 没有快照的周期不补造数据；
- 自定义区间清楚标注实际取值对应的真实快照日期；
- 曲线只连接真实记录点，不暗示未录入期间发生的交易或估值路径。

### 2.2 财富构成图

展示资产配置和负债结构，帮助用户理解财富由什么组成。图表突出分类及占比，同时保留金额信息；分母为零或数据不足时不显示误导性比例。

### 2.3 两快照间的本期变化解释图

展示上次实际快照与本次实际快照之间，各条目账面金额变化对净资产变化的影响。

该图只能解释“哪些已记录条目发生了账面变化”，不能自动判断变化是新增储蓄、还债、市场估值、补录还是汇率变化。没有额外标记时统一称为“账面变化”。

### 2.4 财务安全感面板

集中呈现与财务安全感相关的描述性指标，包括：

- 总负债率；
- 债务偿付压力；
- 现金安全垫；
- 月固定收入；
- 月刚性支出；
- 月度固定结余；
- 在有基础生活费估计时展示估计必要结余。

缺少必要数据、比例分母为零或口径无法解释时，显示“数据不足”或不展示，不猜测数值。

### 2.5 财富目标进度

财富目标进度以当前净资产相对目标设定时真实净资产基线的前进距离计算，不使用“当前净资产 / 目标净资产”的简单比例。

进度展示必须处理负净资产、目标低于或等于基线、超过目标和缺少基线等边界。无法有意义计算时显示“不适用”，并引导用户重新设定目标或补充真实快照。

### 2.6 投资决策时间线

按时间展示用户主动记录的买入和卖出决策、金额、理由及复盘信息，用于建立纪律和回顾决策。

时间线不展示实时行情，不自动计算持仓或收益，也不给出买卖建议。

## 3. 信息层级

### 3.1 成长首页

首页主视觉依次突出：

1. 当前净资产；
2. 相对上次实际快照的本期金额变化；
3. 数据条件允许时的阶段净资产增长率；
4. 净资产成长曲线；
5. 财富目标进度。

首页保持聚焦，不承载复杂归因和金融终端式信息。

### 3.2 分析页

分析页用于理解财富状况，呈现：

- 财富构成；
- 两次快照之间的变化；
- 财务安全感；
- 数据条件允许时的年化财富变化速度。

## 4. 财富目标与里程碑反馈

目标进度设置以下里程碑：

- 25%；
- 50%；
- 75%；
- 100%。

达到里程碑时给予与当前主题一致的正向反馈。达到 100% 时提供更强的庆祝动效、音效和触感反馈，并引导用户设置下一个目标。

所有音效和高强度动效都必须可以关闭。产品尊重系统无障碍设置和“减少动态效果”偏好，在相应情况下提供低动态或静态反馈，不影响信息获取。

## 5. 增长率表达边界

### 5.1 阶段净资产增长率

阶段净资产增长率表示相对上次实际快照的百分比变化，可以用于首页。

上次净资产小于等于零或分母无法合理解释时，不展示百分比，只展示本期金额变化和简明说明。

### 5.2 年化财富变化速度

年化财富变化速度只能在分析页谨慎展示，并必须同时说明：

- 它是净资产账面变化的年化等效速度；
- 其中可能包含工资积累、还债、新增投入和估值变化；
- 它不是“年化收益率”；
- 它不代表投资收益，也不能预测未来。

只有起点净资产为正、时间跨度足够且数据条件适合时才展示；条件不满足时隐藏，不强行计算。

## 6. 主题系统与图表语义

- 同一指标、图表语义和数据口径在所有主题中保持一致；
- 主题只改变色彩、背景、字体层级、图表风格、插画和动效等视觉表现，不改变正负含义；
- 不得使用主题颜色颠倒上涨、下降、资产和负债的含义；
- 下降、市场波动或还债场景均使用稳定、非羞耻化反馈；
- 动效和皮肤必须服务数据理解，不妨碍可读性和无障碍体验。

## 7. 明确不做

- 不虚构用户没有录入的时间点或快照数据；
- 不自动判断账面变化的具体原因；
- 不用净资产变化冒充投资收益；
- 不追踪实时行情；
- 不以插值曲线暗示不存在的交易或估值变化；
- 不将“年化财富变化速度”称为“年化收益率”。
