# MVP 完整 UI 图纸与自检记录

> 本文档汇总 MVP 八组高保真移动优先 UI 图纸及交付前自检结果。图纸用于实施视觉参考，不替代产品、数据模型与无障碍规范。

## 共同视觉与产品边界

- 默认主题采用深靛蓝背景、暖金色成长点缀，薄荷绿仅作辅助状态色；
- 所有主 CTA 使用统一的暖金色填充和深靛蓝高对比文字；
- 首页优先表达财富成长，分析页帮助理解构成与账面变化；
- 所有趋势与对比必须基于真实快照，不补造不存在的时间点；
- 不做逐笔记账、实时行情、自动持仓、券商交易或金融机构 API 接入；
- 不把净资产账面变化称为投资收益，不自动判断账面变化原因；
- 下降、波动与还债场景采用稳定、非羞耻化表达；
- MVP 本地优先，无账号、无同步、无备份或导入导出。

## 01. 首次信任引导

![首次信任引导](01-首次信任引导.png)

**页面与状态**

- 产品定位页；
- 数据安全信任页；
- 首次资产建档入口。

**必须保留**

- 先建立信任，再请求财务数据；
- 明确数据只在本机、不接金融机构、卸载或设备变化可能丢失；
- 现金与存款、投资资产、不动产、负债四个渐进式入口；
- 三屏主 CTA 使用完全一致的暖金体系。

**修订与自检**

- 已修订：统一原首轮图中不一致的绿/深蓝主按钮；
- 已修订：移除与 MVP 边界冲突的导出备份提示；
- 最终检查通过：CTA、信任信息、渐进式建档与视觉气质一致。

## 02. 资产档案

![资产档案](02-资产档案.png)

**页面与状态**

- 资产条目列表与财富全貌入口；
- “添加第一笔资产”录入页。

**必须保留**

- 条目按资产与负债类别清晰组织；
- 首次录入只要求最小必要信息，更多详情可后补；
- 名称、所属机构或平台、分类、当前余额或估值清楚可见；
- 用户可继续添加，也可先生成财富全貌。

**修订与自检**

- 已修订：所属机构或平台恢复为必填口径；
- 已修订：移除未确认的“种子计划”导航名，统一为“目标”；
- 最终检查通过：渐进式录入、模块命名、CTA 和本地数据提示符合既定范围。

## 03. 首页成长反馈

![首页成长反馈](03-首页成长反馈.png)

**页面与状态**

- 当前净资产与本期账面变化；
- 阶段净资产增长率；
- 真实快照成长曲线；
- 基于设定时净资产基线的财富目标进度。

**必须保留**

- 净资产是首页第一信息；
- 图表只连接真实快照点，并显示真实快照日期；
- 目标进度按“当前相对基线的前进距离”计算；
- “更新资产近况”为暖金主 CTA。

**修订与自检**

- 已修订：纠正目标进度、基线与 25/50/75/100% 里程碑金额；
- 最终检查通过：信息层级清楚、曲线口径真实、情绪表现不遮挡数据。

## 04. 更新资产近况

![更新资产近况](04-更新资产近况.png)

**页面与状态**

- 按上次真实快照更新条目；
- 提交前确认修改项和沿用项；
- 生成本次真实快照。

**必须保留**

- 用户只修改发生变化的余额；
- 未修改条目标记并沿用上次值；
- 提交前显示本次修改与沿用数量；
- 明确新快照使用真实日期，历史快照不可修改。

**修订与自检**

- 首版生成后通过最终检查，无需额外修订；
- 最终检查通过：修改/沿用状态、快照日期、不可变历史和主 CTA 均明确。

## 05. 资产分析

![资产分析](05-资产分析.png)

**页面与状态**

- 资产构成与负债结构；
- 两个真实快照间的本期账面变化；
- 财务安全感描述指标；
- 年化财富变化速度的数据不足状态。

**必须保留**

- 只描述已记录条目的账面变化，不自动归因；
- 安全感指标保持描述性，不提供改进建议；
- 年化财富变化速度不称年化收益率；
- 时间跨度不足时不展示年化数值。

**修订与自检**

- 已修订：移除“查看改进建议”和评价式指标徽章；
- 已修订：将结构评价改为中性结构摘要；
- 已修订：一个月跨度下隐藏年化财富变化速度；
- 最终检查通过：分析信息完整，没有投资建议或自动归因。

## 06. 目标管理与达成

![目标管理与达成](06-目标管理与达成.png)

**页面与状态**

- 设定财富目标；
- 目标进度与四级里程碑；
- 100% 达成庆祝。

**必须保留**

- 设定日真实净资产作为基线；
- 目标进度按基线到目标的前进距离计算；
- 25/50/75/100% 里程碑金额与公式一致；
- 达成动效不遮挡金额，音效和强动效可关闭。

**修订与自检**

- 已修订：纠正进度、推进金额、剩余金额与里程碑数学关系；
- 已修订：移除“进度不受短期波动影响”的错误陈述；
- 已修订：目标超额只显示金额，避免简单百分比误导；
- 最终检查通过：进度口径、100% 庆祝、无障碍提示和 CTA 一致。

## 07. 投资决策日志

![投资决策日志](07-投资决策日志.png)

**页面与状态**

- 决策日志空时间线；
- 买入或卖出决策录入与复盘字段。

**必须保留**

- 日期、金额、理由为核心记录；
- 关联条目、数量、标的、计划、结果与复盘为可选；
- 明确仅用于纪律与复盘；
- 不提供行情、交易执行或买卖建议。

**修订与自检**

- 已修订：移除可能被误认为真实交易的虚构标的、金额与理由，改为空状态和空表单；
- 最终检查通过：日志定位明确，没有券商界面、实时行情或交易建议。

## 08. 提醒与设置

![提醒与设置](08-提醒与设置.png)

**页面与状态**

- 月度、周度、自定义或关闭提醒；
- 应用锁、本地数据说明、主题切换和辅助功能。

**必须保留**

- 默认月度提醒并允许用户选择提醒日；
- 提醒不是打卡；
- 应用锁支持密码或生物识别；
- 明确本地数据丢失风险及 MVP 无备份导出；
- 主题入口包含首发 2 至 3 套主题；
- 不出现云端、账号或金融机构连接。

**修订与自检**

- 已修订：设置页主按钮由“保存提醒”更正为“保存设置”；
- 最终检查通过：提醒与设置职责清楚、主 CTA 一致、无越界功能。

## 共同实施边界

八组图纸的视觉方向与页面结构已经完成内部自检，可提交用户统一验收。

图纸中的精确文案、控件尺寸、响应式规则、动效时序、触感与音效参数，以及无障碍详细规范仍需在实现前补充确认。后续实现不得仅凭图片臆造这些细节，也不得绕过产品文档与数值模型中已经确定的边界。
