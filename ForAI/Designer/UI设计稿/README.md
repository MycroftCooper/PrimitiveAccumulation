## 首次信任引导与资产建档（首轮）

![首次信任引导与资产建档首轮 UI 设计](首次信任引导与资产建档-首轮.png)

该首轮图纸已经确认，可作为后续 UI 实现的视觉基准。从左到右分别为产品定位页、数据安全信任页和首次资产建档入口。

三页必须保留的要点：

- **产品定位页**：保留深靛蓝与金色的财富成长气质，以及存钱罐意象；
- **数据安全信任页**：清楚呈现本地存储、不接金融机构和数据主权，不用视觉氛围掩盖事实；
- **首次资产建档入口**：保留现金与存款、投资资产、不动产、负债四个类别的渐进式建档入口。

以下细节尚未确定：

- 精确文案；
- 控件尺寸；
- 动效时序；
- 无障碍细节。

后续设计与实现不能仅凭图片臆造这些未确定内容，应继续结合已确认产品文档逐项讨论和确认。

历史首轮图纸继续保留，用于追溯已确认视觉方向；MVP 实施参考以完整图纸和自检记录中的最终版本为准。
